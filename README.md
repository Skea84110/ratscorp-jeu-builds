# ratscorp-jeu-builds

Builds WebGL publics du jeu de RatsCorp (game.ratscorporation.com).

Ce dépôt ne contient QUE les fichiers du dossier `Build/` d'un build Unity déjà destiné à être servi à tous les
joueurs : aucun code source, aucun secret. Chaque release porte les quatre fichiers d'un build.

L'intégrité ne se lit pas ici : la page du jeu vérifie chaque fichier (taille et sha256) contre un manifeste commité
dans son propre dépôt, relu avant d'être accepté. Une release modifiée après coup est refusée par la construction.
